# renesas,ra-ospi-b-nor (on ospi bus)

[drivers/flash/flash\_renesas\_ra\_ospi\_b.c](https://github.com/zephyrproject-rtos/zephyr/blob/main/drivers/flash/flash_renesas_ra_ospi_b.c).
