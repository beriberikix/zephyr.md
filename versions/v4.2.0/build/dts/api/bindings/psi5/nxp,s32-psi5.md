# nxp,s32-psi5

Vendor: [NXP Semiconductors](../../bindings.md#dt-vendor-nxp)

Note

[drivers/psi5/psi5\_nxp\_s32.c](https://github.com/zephyrproject-rtos/zephyr/blob/main/drivers/psi5/psi5_nxp_s32.c).

## Description

```text

```
