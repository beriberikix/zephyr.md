## [◆ ](#a6e9d013c0dc687f05c27dc907bb56c65)sensor\_channel\_pat9136

| enum [sensor\_channel\_pat9136](#a6e9d013c0dc687f05c27dc907bb56c65) |
| --- |

This sensor does have the ability to provide DXY in meaningful units, and since the standard channels' unit is in points (SENSOR\_CHAN\_POS\_DX, SENSOR\_CHAN\_POS\_DY, SENSOR\_CHAN\_POS\_DXYZ), we've captured the following channels to provide an alternative for this sensor.

| Enumerator | |
| --- | --- |
| SENSOR\_CHAN\_POS\_DX\_MM | Position change on the X axis, in millimeters. |
| SENSOR\_CHAN\_POS\_DY\_MM | Position change on the Y axis, in millimeters. |
| SENSOR\_CHAN\_POS\_DXYZ\_MM | Position change on the X, Y and Z axis, in millimeters.  Added additional offset so the channels X and Y can be accessed relative to XYZ in spite of not supporting DZ. |
